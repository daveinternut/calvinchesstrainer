# Google Play store assets — Calvin Chess Trainer

Generated 2026-07-23 from release builds running on purpose-built Android emulators.
All screenshots are **exactly 9:16** (0.5625), which is what the Play Console requires
("16:9 or 9:16 aspect ratio"). The app is portrait-locked, so 9:16 is the only option.

## What goes where in the Play Console

| Play Console field | Use these files | Spec | Status |
|---|---|---|---|
| **App icon** | `icon-512.png` | 512×512, ≤1 MB | ✅ 512×512, 103 KB |
| **Feature graphic** | `feature-graphic-1024x500.png` | 1024×500, ≤15 MB | ✅ 1024×500, 91 KB |
| **Phone screenshots** | all 6 in `phone/` | 2–8 shots, 9:16, sides 320–3840 px | ✅ 1080×1920 |
| **7-inch tablet screenshots** | all 4 in `tablet/` | ≤8 shots, 9:16, sides 320–3840 px | ✅ 1440×2560 |
| **10-inch tablet screenshots** | all 4 in `tablet/` | ≤8 shots, 9:16, sides 1080–7680 px | ✅ 1440×2560 |

The same `tablet/` files satisfy **both** tablet slots: 1440×2560 falls inside the 7-inch
range (320–3840) and the 10-inch range (1080–7680). Upload the same four to each.

All phone shots are ≥1080 px per side and there are ≥4 of them, so the listing qualifies
for Google's **promotion eligibility** bar.

## How these were produced

Stock Pixel AVDs are all ~9:20 (e.g. Pixel 9 Pro is 1280×2856) and would be **rejected**
for violating the 9:16 rule, so two custom AVDs were created:

```bash
# PlayShots_Phone  = 1080x1920 @ 420dpi
# PlayShots_Tablet = 1440x2560 @ 320dpi
avdmanager create avd -n PlayShots_Phone -k "system-images;android-35;google_apis;arm64-v8a" -d pixel_5
# then hw.lcd.width/height/density patched in ~/.android/avd/<name>.avd/config.ini
```

The app was installed as a **release** APK (`flutter build apk --release --target-platform android-arm64`)
so there is no Flutter debug banner.

Android demo mode was enabled for a clean status bar (fixed 9:00 clock, full battery, no
notifications). On the phone AVD the status bar still rendered clipped, so the top 92 px and
bottom 72 px strips (status bar / gesture nav pill) were filled with the app's own background
color `rgb(247,251,241)` sampled from the corner — this preserves exact 1080×1920 with **no
cropping, scaling, or distortion**. Tablet used 70 px strips.

### `feature-graphic-1024x500.png`

Generated by [`scripts/make_feature_graphic.py`](../../../scripts/make_feature_graphic.py) —
re-run it from the repo root to regenerate after any brand tweak:

```bash
python3 scripts/make_feature_graphic.py   # needs Pillow
```

Composition: diagonal green gradient (sampled from the app icon) with a faint chessboard
texture, the app icon as a cream-ringed badge, the title set in the app's own display font
`assets/fonts/BradBunR.ttf`, and four colour chips hinting at the four trainers.

Note: Chess Notation's real card colour is a dark green that disappears against this
background, so its chip uses a brightened tint of the same hue purely for contrast. Every
other colour is the app's exact value.

Per Google's guidance the graphic carries no device frames, no screenshots, no store badges,
and no "download now" call-to-action, and all text sits well inside the safe area so nothing
is lost if Play crops the edges.
